# Визуальный стандарт карточек упражнений

Карточки строятся из проверенных фотографий техники, поверх которых допускается
AI-обработка с одним утверждённым образом девушки и одним спортивным костюмом.
Личные фотографии-референсы не попадают в репозиторий или на VPS. Итоговая карточка
публикуется только после ручной проверки пользователем обеих фаз и внешнего образа.

Источником истины для состава карточек, URL источников, авторства, лицензий, контрольных
сумм и статуса ручной проверки служит
[`app/assets/exercises/manifest.json`](../app/assets/exercises/manifest.json). Если для
упражнения нет точной лицензированной пары фотографий, бот должен показать текстовую
технику без изображения; подмена другим тренажёром запрещена.

## Макет карточки

- итоговый PNG: 1254×1254, RGB, без EXIF;
- для силового упражнения — два одинаковых по размеру кадра с фиксированными
  отступами и разделителем;
- для дорожки, эллипса и велотренажёра — одна фотография без искусственных фаз;
- название упражнения, короткие подписи фаз и не более двух строк подсказки под каждым
  кадром;
- источник и лицензия указываются в нижней части карточки;
- фотографии кадрируются пропорционально, без растяжения, логотипов и водяных знаков;
- для силовых упражнений используются подписи `Исходное положение` и
  `Конечное положение`;
- кардио содержит только название и одну короткую подсказку.

## Проверка фаз и допуска к публикации

До включения изображения в Telegram человек вручную сверяет оба кадра с текстом техники:
настройку тренажёра, положение суставов, хват, траекторию, амплитуду и соответствие
исходной и конечной фаз. Одна сводная контактная таблица показывается пользователю до
публикации.

Статус `approved` в манифесте ставится только после этой проверки. Карточка с другим
тренажёром, перепутанными фазами, визуальным артефактом или несовпадающей контрольной
суммой не публикуется и остаётся в текстовом fallback-режиме.
